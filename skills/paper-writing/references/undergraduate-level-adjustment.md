# 本科大四水平论文特征

当用户要求"改写成本科四年级学生的水平""现在显得太专家了"时，对论文进行以下调整：

## 降级改动清单

### 句式层面
- 拆分复合长句（>30词）为多个短句（15-20词）
- 减少嵌套从句——每句最多一层从句
- 多用主动语态："This study found..." 而非 "It was found that..."
- 少用分号和破折号连接子句

### 词汇层面
| 专家级 | 本科级 |
|--------|--------|
| conceptual architecture | structure / framework |
| institutionalization | growth / establishment |
| paradigm shift | major change |
| epistemological | understanding |
| operationalization | putting into practice |
| reconfigured | changed / rearranged |
| disproportionately concentrated | mostly found in |
| conceptual accretion | adding new ideas on top of old ones |

### 语气层面
- 从"we argue that..." → "this study suggests that..."
- 从学术距离感 → 直接陈述发现
- Discussion 从理论辩论 → 基于数据的清楚解释
- 减少"however""nevertheless""conversely"等转折词的堆叠

### 保持不变的部分
- 数据（数字、百分比、表格内容）
- 检索式
- 参考文献格式和内容
- 图表
- 研究问题和研究设计

## 同步更新关联文档

可行性评估报告和文献综述也应用同一水平改写——删除复杂术语，简化句式，保持结构不变。
